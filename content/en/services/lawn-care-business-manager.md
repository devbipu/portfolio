faq:
  heading: Questions
  questions:
    - title: Do I have to pay a monthly subscription?
      answer: >-
        No mandatory monthly software subscription is required for the custom
        application itself. Normal hosting and third-party service costs -
        server, domain, email and SMS providers, payment processing - may still
        apply, and optional maintenance is billed separately if you want it.
    - title: Can the software run on my own server?
      answer: >-
        Yes. The application can be deployed to infrastructure you control,
        depending on the project's technical requirements. We agree on the
        hosting setup during scoping so there are no surprises at deployment.
    - title: Can you integrate my existing tools?
      answer: >-
        Yes. Depending on the service, integrations can be built for payments,
        email, SMS, maps, calendars, CRMs, accounting tools and other APIs.
        Which ones are practical depends on what those services expose.
    - title: Do I need all these features?
      answer: >-
        No. The goal is to build only what your business needs. Most projects
        start with two or three modules that remove the worst of the manual
        work, and grow from there.
    - title: Can you migrate my spreadsheet data?
      answer: >-
        Where it is technically practical, existing spreadsheet and customer
        data can be imported into the new system. How clean the import is
        depends on how consistent the existing data is.
    - title: Can you maintain the application?
      answer: >-
        Yes. Ongoing maintenance, updates, bug fixes and additional features
        can be provided separately. This is an optional arrangement, not a
        condition of the build.
    - title: Is this suitable for a small business?
      answer: >-
        Yes. The system can start small - a single owner with two crews is a
        perfectly normal starting point - and grow as the business grows.
    - title: Is this the same as buying a SaaS product?
      answer: >-
        No. Instead of subscribing to a generic platform, this is custom
        software developed around your business workflow, which you can then
        run on your own infrastructure.
