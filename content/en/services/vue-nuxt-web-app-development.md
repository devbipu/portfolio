faq:
  heading: Questions
  questions:
    - title: Can you fix the SEO on an existing Vue single-page app?
      answer: >-
        Usually, yes. The common fix is moving the pages that need indexing
        onto server-side rendering or static generation with Nuxt, which can be
        done route by route rather than as one rewrite.
    - title: Can you migrate a Vue 2 project to Vue 3?
      answer: >-
        Yes. It is done incrementally - dependencies and build tooling first,
        then components in groups, with the app working throughout. A fixed-cost
        rewrite is rarely the cheaper route.
    - title: Do you work with an existing backend?
      answer: >-
        Yes, and that is the normal case. Laravel, Node, Django, a headless CMS
        or a third-party API all work. If the API is awkward to consume, I will
        say so and suggest what would make it easier.
    - title: Do you do the design as well?
      answer: >-
        I build from a design when you have one, and I can design straightforward
        interfaces where you do not. For anything brand-heavy you will get a
        better result from a designer, and I will work to their files.
    - title: Will it work on mobile?
      answer: >-
        Yes - built mobile-first and tested on real viewport sizes and a
        throttled connection, not just by narrowing a desktop browser window.
    - title: What about accessibility compliance?
      answer: >-
        Semantics, keyboard paths, focus management, labels and contrast are
        checked against WCAG 2.1 AA as part of the build. A formal audit by a
        specialist is a separate exercise, but you should not be starting it
        from zero.
    - title: Can you set up a component library for my team?
      answer: >-
        Yes. That includes the tokens, the base components, the documentation
        and the conventions, so your developers add to it in a consistent way
        after handover.
    - title: Where can it be hosted?
      answer: >-
        Netlify, Vercel, Cloudflare Pages, a Node server or static hosting -
        the right choice depends on whether you need server-side rendering,
        where your users are, and what your team already runs.
